# 📚 Rule-Based Book Recommendation System

A Python-based Artificial Intelligence mini project that recommends books based on the user's preferred genre, reading level, and mood.

## 📌 Project Overview

This project uses a rule-based expert system to suggest suitable books. It applies IF–THEN rules, forward chaining, and backward chaining to generate recommendations and explain its decisions.

## ✨ Features

- 📖 Knowledge base of 56 books
- 🎯 Recommendations based on genre, level, and mood
- 🧠 IF–THEN production rules
- 🔄 Forward chaining for book recommendations
- 🔍 Backward chaining to verify a selected book
- 💻 Simple browser-based interface
- 📋 Displays rules fired and reasoning steps

## 🛠️ Technologies Used

- Python 3
- HTML
- CSS
- Python Standard Library

## 📚 Available Categories

**Genres:** Fantasy, Sci-Fi, Mystery, Self-Help, Technology, History, Fiction

**Reading Levels:** Beginner, Intermediate, Advanced

**Moods:** Relaxed, Excited, Thoughtful, Motivated

## ⚙️ How to Run the Project

**Prerequisite:** Python 3 installed on your computer.

1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run the following command:

```bash
python book_recommender.py
```

4. Your default browser should open automatically.
5. If it doesn't, visit `http://localhost:8000`.
6. Select your genre, reading level, and mood.
7. Click **Recommend / Verify** to view recommendations.

Press `Ctrl + C` in the terminal to stop the server.

## 🧠 AI Concepts

### Forward Chaining
Starts with known user preferences and applies rules to derive facts that help recommend books.

### Backward Chaining
Starts with the goal of verifying a selected book and checks whether the required conditions can be proved.

### Knowledge Base
Stores book information, including title, author, genre, reading level, and tone.
